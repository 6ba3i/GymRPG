# gymrpg-anatomy

Two vector views, not 3D. Source geometry from audited MIT/Apache-2.0 anatomy repos. Stable names for each mapped muscle and subdivision; source-to-canonical IDs require a documented crosswalk. Render individual paths, hit test, apply separate group ranks and subdivision heatmaps, crossfade Front/Back and animate scale/translation for focus. Never create fabricated precision for missing SVG regions; emit mapping coverage tests. No Blender, GLB, SceneView, Filament or WebView anatomy.
