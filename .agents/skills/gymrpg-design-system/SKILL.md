# gymrpg-design-system

Read `docs/GymRPG_Technical_Spec_v1.1.md` and its design decisions. Use Google Sans Flex with LastWave-inspired axes and OFL attribution. Dark theme is default; Full Glass and Efficient modes are selectable. Floating five-tab pill navigation, dynamic window insets and 48dp touch targets are mandatory. Evaluate Kyant Backdrop as a library, not as a guaranteed dependency. No content hidden under status, camera or gesture areas; validate real device screenshots.

## Evidence / exit criteria
Before claiming completion, compile affected modules, run applicable fixtures/tests, and explain any device-only limitations. Record changed files and results. Never use external examples to override the project's v1.1 specification.
