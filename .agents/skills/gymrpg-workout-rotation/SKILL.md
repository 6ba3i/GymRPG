# gymrpg-workout-rotation

Monday Push, Tuesday Pull, Wednesday Legs, Thursday Upper, Friday Lower, weekend rest; missing sessions must not move weekday assignments. Immutable template versions and completed-session snapshots. Determine eligible trained muscle subdivisions from comparable evidence, normalize exercise change without comparing raw cross-exercise loads; at least 50 percent stagnating for three consecutive executions of the SAME template triggers sequential rotation. Incomplete subdivisions are excluded, version changes reset relevant baselines, and skip logic is explicit. Run golden fixtures.
